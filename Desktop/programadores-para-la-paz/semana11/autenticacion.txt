El login es el proceso mediante el cual un usuario ingresa a una aplicación utilizando sus credenciales para identificarse. Esto permite verificar su identidad antes de acceder a determinadas funciones. Algunas rutas deben estar protegidas porque contienen información privada o permiten realizar acciones importantes dentro del sistema. De esta manera se evita que personas no autorizadas accedan a datos o modifiquen la información. No se deben exponer públicamente contraseñas, documentos de identidad, direcciones, teléfonos, tokens, claves de API ni otros datos sensibles de la comunidad.
