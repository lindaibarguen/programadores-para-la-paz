Durante este curso aprendí que la tecnología puede facilitar la participación ciudadana y fortalecer la organización comunitaria. Comprendí cómo desarrollar aplicaciones básicas utilizando Node.js, bases de datos y automatización. También aprendí la importancia de proteger los datos personales de los usuarios y de crear soluciones seguras y útiles para la comunidad. Entendí cómo un sistema puede registrar información, generar documentos automáticamente y enviar notificaciones cuando ocurre un evento importante. Además, reforcé mis conocimientos sobre Git y GitHub para organizar y publicar proyectos. Considero que estos aprendizajes serán de gran utilidad para desarrollar herramientas tecnológicas que beneficien a las comunidades y apoyen la gestión de iniciativas ciudadanas.
